# WorkCore E6 最终外观设计包

> **状态更新：原始自由生成图及其未锚定结论已否决。** 它们未继承 E6-DFR3 STEP 几何，不得使用。纠正版与唯一有效的图像工作流位于 `step_anchored_v2/`。

本目录把 `docs/e6_object_character_and_mystery_brief.md` 作为首要设计准则，并以现有 STEP/CAD 为只读工程硬点。目标不是美化当前样机，而是给最终量产产品建立独立、可审查、可继续深化的外观母体。

## 设计结论

方向名：**Quiet Orbit / 静默轨道**。

E6 应被第一眼识别为一件低矮、完整、平静而有方向性的“个人场域仪器”。它的复古科幻来自轨道时代精密仪器的比例、温度和机械仪式；极简来自低位整体体量、少而准确的分缝和一致曲率；高级感来自真实材料、控制面差、装配精度与动作质感；神秘感来自闭合时未显露的能力，而不是模糊意图、隐藏安全信息或制造机器人表情。

闭合检验句：

> 闭合时像一件安静、完整、拥有未显露能力的新物品；展开时每个变化都自然得像它从来只能这样工作。

## 非破坏性边界

- 不修改、不覆盖、不移动任何现有 `.step` / `.stp` 文件。
- 不把当前样机的箱体、彩色传感块、T 形梁或散落板件冻结为最终产品语言。
- 当前 STEP 仅提供轮组、人体、桌板、脚踏、桅杆、传感器、HMI、安全与服务硬点。
- 新造型后续应以独立 Class-A skin / 外观件 CAD 延续；在工程评审通过前不得侵入运动包络和安全接口。

本设计包是**最终外观方向冻结输入**，不是可直接开模的 Class-A/结构发布件。量产释放仍需通过本目录定义的工程、法规、人因、清洁、装配和场景验证门槛。
