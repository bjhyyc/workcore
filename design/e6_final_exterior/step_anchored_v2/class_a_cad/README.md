# WorkCore E6 V8 STEP-anchored exterior skin CAD

本目录不是给受控样机换材质，而是在版本化 `E6-DFR5-A07-SHARED-HINGE` 四态硬点上建立最终外观候选 CAD。DFR5 原则修订源单独位于 `controlled_source_e6_dfr5/`，含四主态与 Café/Focus 可选脚踏展开验证态；它只修正 Follow 中 A07 与 A06 共用 `(160, 0, 515) mm` 铰链，非 Follow 状态与 DFR4 保持字节一致。原 `build/` 中 E6-DFR3 和父版本 DFR4 文件保持只读追溯。脚本对各层输入分别校验 manifest、字节数和 SHA-256；所有新增 STEP、GLB、PNG 与报告只写入本目录的 `release_candidate_v8/`。

## 权威层级

1. `skin_lower.py`、`skin_upper.py`：A01–A10 外覆分件的参数化源；
2. `validate_class_a.py`：几何、状态、净距、功能界面和源文件绑定硬门；
3. `release_candidate_v8/<state>/workcore_e6_class_a_skin_<state>.step`：仅新增外覆件；
4. `release_candidate_v8/<state>/workcore_e6_class_a_<state>_with_read_only_underlay.step`：外覆件与只读受控底图的关联装配；
5. `release_candidate_v8/<state>/*.glb`、`*.png`：设计评审和 QA，不作为尺寸证据；
6. `corrected_renders/` 中的生成图只保留为方向草图，不是 CAD 交付物。

## 构建

在仓库根目录使用项目的 CadQuery 运行环境：

```powershell
$env:PYTHONPATH=(Resolve-Path '.venv\Lib\site-packages').Path
& 'C:\Users\86135\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' `
  'design\e6_final_exterior\step_anchored_v2\class_a_cad\build_class_a_skin.py'
```

构建是 fail-closed：先写入 `BUILD_INCOMPLETE`，验证内存几何，导出每个分件 STEP，再从导出的 STEP 重新验证几何、刚性碰撞、GLB 清单和 32 张正式图。只有制品闭包通过、最终 manifest 已原子写入后，脚本才把移除 `BUILD_INCOMPLETE` 作为最后一次发布写操作。不得手工删除该标记；正式完成必须同时满足 manifest 全部数字门为 `PASS`、标记不存在，并以 manifest 只读复核封闭制品集为 `PASS`。

四态共用的 A01 前鼻壳包含永久一体式 front brow 与短上回边，用真实 B-Rep 闭合感知地平线上方脚舱的正常前视、站立及斜上视线；它不是 Follow 专用盖板，也不改变同一梯形靠背的折叠责任。乘员侧脚部通道、感知硬点和 A04 干式分缝由独立门禁保留。

A03 连续轮罩采用不可混用的双区包覆合同：大面积外侧皮只开放 `z=0–32 mm` 的低位接地条，必须通过侧面 `z=20 mm` 开放、`z=55 mm` 闭合探针；仅前后纵向端回因轮胎变形、排水和运动边界保留局部 `z=0–70 mm` 让位，必须通过端部 `z=55 mm` 开放、`z=90 mm` 闭合探针，并在跨轮胎宽度三点和上半部三高度通过 3×3 实体覆盖网格。四个端回还必须各有一件独立月岩体色外层冲击皮：名义厚 `1.0 mm`、与深色结构端回干隙 `0.1 mm`、覆盖 `Y=88.6 mm` 和 `Z=71–314 mm`；深色结构端回本身通过覆盖网格不等于视觉通过。端部让位不得解释为侧面或差速轮整体外露，正/后视不得读成竖向整块黑色轮胎。四轮在 `-10/-5/0/+5/+10°` 的轮罩扫掠净距均为 `15.5 mm`，轮端近齐平硬盖和随盖 EPDM 背衬分别保持 `16.3/15.6 mm`。轮罩名义宽度为 `750.8 mm`、轮端盖局部成品宽度为 `751.0 mm`，均受 `752 mm` 量产设计上限约束。

四态同一右侧 pod、直立摇杆和授权键必须保持相同物理 ID、相同 B-Rep 与同一扶手前端世界坐标，并始终外露；只有 Ride 的锁定态允许牵引。Café/Focus 使用 `140×104×120 mm` 真实操作手包络复核全部 A09 桌板与下部结构，最短干隙不得低于 `5 mm`，不能用“电气禁用”解释桌板遮挡或手无法到达。

左右 A04/A05 连续侧帆以 2 mm RF 透明外皮维持原 V8 的单一平静侧场：UWB 只在内侧做 `0.8 mm` 浅避让，实测外皮必须保留至少 `1.2 mm`，到原硬点 bezel 零干涉且名义干隙 `0.3 mm`；不得开出贯穿的深色长槽。A05 重力排水口仍是独立的 `34×18 mm` 小开口并与侧帆实体零干涉。

A06 根部的固定 A05 壳对 bearing、完整 shaft 和 lock disc 分别执行零公共体积与 `0.6/0.7/0.7 mm` 干隙门禁。Follow/Ride/Café 的 A05 固定壳 B-Rep 相同；Focus 的差异只有在未让位壳确实无法达到 A09 的 `1.5 mm` 干隙、且全部减材局限于三段真实升降级走廊时才成立，因此它是必要包装让位，不是随状态任意改壳。

四态外包络采用“受控 STEP 六面边界 + 独立总尺寸”双锁：纵向 `xmin/xmax` 各自最多允许 `25 mm` Class-A 表皮/回边增量，不能把整机平移来消费另一端余量；同时总长分别受 Follow/Ride/Café/Focus 的 `885/1111/906/1021 mm` 上限约束。横向逐面增量最多 `17 mm`，并继续受 `752 mm` 成品总宽硬上限约束。该规则明确区分“两端各有必要回边”和“单端越界”，不允许用放宽总长掩盖硬点漂移。

A07 的 Focus 位移只作用于同一移动脊柱、冠梁及其功能件：固定套筒不动，延伸捕获为 `150 mm`。移动脊柱通过 `16 mm` 隐藏空心榫进入冠梁套口，具有 `3 mm` 径向装配间隙、`2 mm` 端余隙及 `4 mm` 外观干缝；下置声学网位于结构榫外侧并保持至少 `1.5 mm` 真实干隙，不允许以网片穿入结构件冒充开孔。Ride/Café 保留同一低位感知地平线，Follow 与 A06 共铰折叠，不存在 Focus 临时出现的另一根桅杆。

A10 后服务围框在 A06 连续通道的隐藏视线内设置 `62.4×128.4×72 mm` 真实桅杆通过槽；Ride/Café 的低位移动脊柱对围框实测最小干隙为 `3.642967 mm`，硬门仍为 `3.5 mm`，不使用碰撞白名单。物理隐私快门边框不是贴花：冠梁具有覆盖闭合中心 `Y=-8 mm` 到 Focus 停放中心 `Y=128 mm` 的连续滑架口袋，名义让隙 `0.2 mm`，四态要求零刚体公共体积。

Café 右叶和 Focus 双叶的 A09 根部各使用一件连续收腰空心桌腹；旧 bridge、root fairing、saddle、方盒 belly 及其布尔 service fragment 已从正式发生项退休。三级独立升降件冻结为直壁 XY 定向 squircle 仪器套筒：外截面依次为 `72×70 / 60×58 / 48×46 mm`，内截面为 `66×64 / 54×52 / 40×40 mm`，相邻径向干隙均为 `3.0 mm`，最内级保留 `40 mm` 机构通道；不旋转轴线、不改变 Z 硬点。底部 socket 对第一级的实际最短干隙不得低于 `2.4 mm`；Focus 固定 A05 内缘以受控退让保持 `1.5 mm` 动静干隙，左右桌腹将中央膝部净通道扩大并冻结为 `250 mm`。Focus 独立 root crown、12 mm 桌面中缝和固定 A05 扶手仍保持功能硬点与维修责任。

Focus 每片桌叶的两套机械释放框与拨片位于各自内侧竖直边的 `|Y|=10 mm` 位置，顶面投影为零；到独立 TPE 中缝密封条的名义干隙为 `0.6 mm`，不得恢复跨越中缝的顶置“钢琴铰链”高光。

## 四态输出

- `follow/`：闭合伴随态；只有同一块梯形靠背折叠并直接形成唯一上表面，不增加箱盖、罩壳或第二块遮盖物；A07 固定套筒、单一移动脊柱和同一冠梁先锁定为低态，再与 A06 共用同一铰链折叠。折叠壳只允许对明确标记为非刚性的座垫泡棉形成不超过 `22 mm` 的无乘员名义预压，必须由占用互锁阻止载人折叠，并等待供应商压缩曲线与实体循环验证。
- `ride/`：载人态；脚踏展开、桌面完全收纳、右侧控制权可读。
- `cafe/`：仅右桌展开，左侧保持开放；脚踏默认收纳，双脚可落地。
- `focus/`：同一双桌闭合为工作边界；Ride/Café 已存在的同一 A07 低位感知地平线仅将单一移动脊柱和冠梁上移 420 mm，固定套筒不动；同一右侧控制 pod/直立摇杆/授权键仍固定外露于扶手前端但牵引禁用，桌板不得遮挡；脚踏默认收纳，双脚可落地。

Café/Focus 可以在用户明确请求、产品驻车且扫掠区清空时展开同一 A08 脚踏；这两个可选子状态进入源 CAD 终态、21 点运动扫掠、脚落地路径以及 Class-A 导出前/后静态刚性碰撞验证，但不计入四态 32 张主渲染。正式构建同时逐文件复核这两个子态的 STEP/GLB 与受控 manifest 绑定，不能只凭 manifest 文件存在便继承结论。A08 的平台、左右支撑、左右护套和手动正锁在六态中保持同一物理 ID、材料、B-Rep、定义修订与 `1.890987 kg` 总质量。

每态包含：逐件 STEP、skin-only STEP、带只读底图的关联 STEP、最终评审 GLB、透明底图 QA GLB，以及 hero、QA overlay、front、rear、left、right、top、bottom 八张 1600×1200 正式图。四态共 32 张。`release_candidate_v8/class_a_skin_manifest.json` 记录受控源哈希、完整生成器/设计决策链的构建前后哈希、正式分件数、边界、输出路径、验证门和每个交付文件的 SHA-256；`release_candidate_v8/class_a_validation.json` 保存导出后硬门证据。任何数量或状态结论均以本次正式 manifest 和其引用报告为准，不沿用旧轮次数字。

## 解释边界

这里的结果是可验证、可分件、与受控硬点关联的 **V8 Class-A 外覆方向 CAD / A-surface envelope study**，不是量产 Class-A 曲面放行，也不是结构、安全、法规或量产认证。真正量产放行仍需 Alias/ICEM 级曲率连续性、拔模/分型/壁厚/卡扣与密封工程、供应商 DFM、全运动实体样机、传感透过、清洁老化、人因与法规验证。不能因为数字门通过就跳过这些门。
