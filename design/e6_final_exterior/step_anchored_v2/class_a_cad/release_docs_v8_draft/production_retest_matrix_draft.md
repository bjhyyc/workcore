# WorkCore E6 V8 工业化复测矩阵（草案）

文档状态：`V8 数字 CAD 候选复测矩阵源；正式数字状态以同版 manifest 与报告为准`

量产放行状态：`NOT CERTIFIED / BLOCKED（静态数字 CAD 证据不构成量产认证）`

## 1. 证据等级与判定规则

| 等级 | 证据定义 | 当前可支持的结论 |
|---|---|---|
| L0 | 名称、元数据、责任声明 | 只能证明记录存在，不能证明几何或性能 |
| L1 | 静态 B-Rep、哈希、导出回读、数字清单 | 可证明指定姿态的数字几何和配置完整性 |
| L2 | 运动学/公差/热/结构/RF 数字仿真 | 可支持工程设计收敛，不能替代实体试验 |
| L3 | 功能台架、材料试片、局部总成样机 | 可验证局部物理性能 |
| L4 | 全尺寸工程样机与真实场景试验 | 可支持 DVT/PVT 决策 |
| L5 | 第三方认证、量产过程能力和签署记录 | 才可进入法规与量产放行 |

V8 只有在正式 manifest 引用的 pre-export、post-export、post-STEP、碰撞、GLB、raster 与制品闭包报告全部为 `PASS`，并且 `BUILD_INCOMPLETE` 不存在时，才能把对应结果记为 L1 数字证据。L2 至 L5 的完成结果均为 `TBD`。

判定规则：任何硬门失败即停止升级；没有报告、原始数据、样本编号、环境条件和责任人签署的项目一律记为 `TBD`，不得记为通过。

## 2. 复测触发规则

以下变化至少触发对应行及其下游行重新测试：

- 受控 STEP、姿态或硬点变化：重跑全部数字门、运动包络、结构、热、RF、人因与法规影响分析；
- 外壳面、分件线、壁厚或材料变化：重跑 Class-A、DFM、公差、热、RF、环境、清洁与 CMF；
- A05/A07/A08/A09/A10 机构或开口变化：重跑碰撞、夹剪点、排水、无电释放、误用、疲劳和服务测试；
- A08 默认姿态、可选子态、物理 occurrence、平台定义或质量变化：除完整四态数字门外，重跑 Café/Focus 可选展开端点、全行程扫掠、足部落地路径、配置质量和 32 图范围审计；
- 传感窗、涂层、金属装饰或紧固件变化：重跑光学/RF/EMC、环境老化与可维护性；
- 软件状态机、灯声屏时序或权限变化：重跑四态识别、故障退化、隐私、低电/离线和真实中断恢复；
- 供应商、工艺、模具穴号或材料批次变化：重跑首件、尺寸能力、CMF、环境和可靠性抽检。

## 12. 每轮复测的最低输出

每次复测必须保存以下内容；缺一项则结果为 `TBD`：

1. 测试对象的硬件、软件、CAD、材料和供应商版本；
2. 原始数据、照片/视频、环境条件、设备编号和校准状态；
3. 预先冻结的通过门槛，而不是测试后修改的解释；
4. 失败复现步骤、根因、纠正措施和回归范围；
5. 报告 SHA-256、责任人、复核人和日期；
6. 对四态和典型场景的影响判断；
7. 明确的 `PASS`、`FAIL` 或 `TBD`，不得使用模糊中间词；
8. 对数字 CAD 轮次，保存同次构建的正式 manifest、pre/post 报告、32 图 raster 报告、逐文件 SHA-256 和发布后只读制品闭包结果；
9. 对数字 CAD 轮次，明确记录 `BUILD_INCOMPLETE` 是否存在；标记存在时无条件判为未完成。
