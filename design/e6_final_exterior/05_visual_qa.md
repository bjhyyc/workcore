# 05 — 视觉概念复核

复核依据为 `docs/e6_object_character_and_mystery_brief.md`、本目录 01–03 规范以及现有工程硬点。三张图锁定的是设计语言与状态关系，不是尺寸准确的 CAD 投影。

## 复核结果

| 项目 | 结果 | 说明 |
|---|---|---|
| 一件新物品，而非样机美化 | 通过 | 低位整体、嵌套上壳和统一曲率消除了方箱叠放与零件散落感 |
| 复古科幻 / 极简 / 平滑 / 高级 / 神秘 | 通过 | 气质主要由轨道仪器比例、暖矿物 CMF、烟熏功能材料和精确揭边形成，无道具化符号 |
| Follow 闭合完整性 | 通过 | 座、控制、桌和桅杆均被收纳；仍保留方向、感知与接地真相 |
| Ride 人为主体 | 通过 | 低靠背、开放座舱、脚踏与物理控制清楚；未形成高包围驾驶舱 |
| Café 社交非对称 | 通过 | 单侧桌叶显露、对侧开放；后续 CAD 必须用真实前移—旋转—回位轨迹实现 |
| Focus 工作场 | 条件通过 | 双桌和升起观测脊柱成立；后续需按 430 × 270 mm 双桌、705 mm 高度、10–20 mm 防夹缝与头部净空校正 |
| 感知不拟人 | 通过 | 低位连续语法中保留真实材料分段和短方向光标，不构成人脸 |
| 隐私 / 安全不神秘 | 通过 | 物理隐私片、机械急停和方向光标可见；最终灯语仍需冗余声/触觉验证 |
| 服务与清洁 | 条件通过 | 齐平服务门、可替换下裙和排水逻辑已表达，但实际拆装空间、紧固与液体路径需工程样机验证 |
| 工程几何一致性 | 未作为图像通过项 | 生成图不能证明轮心、间隙、人体、传感视场、扫掠体、散热或结构；必须在独立 Class-A CAD 中逐项回归 |

## 图像中不得直接抄入 CAD 的部分

- 任何由透视造成的轮距、轮心、壳体厚度和离地间隙；
- Follow 上盖分片、Café 桌支撑、Focus 桅杆截面和桌面悬挑的具体尺寸；
- 感知窗内部元件排布、急停底座、服务门锁和排水孔的生成式细节；
- 所有未被接口控制文件确认的曲面分件、紧固方式和材料边界。

## 下一阶段 Class-A 建模输入

1. 复制只读硬点到新的外观装配，先建立轮胎、人体、桌/脚踏/桅杆全行程、传感视场和服务工具禁止侵入体。
2. 以主视图的大体量、高光和三条主线建主表面，不以局部生成细节倒推结构。
3. 用四状态板校验同一壳体的闭合与显露逻辑；每个动作必须对应真实铰链、导轨、锁止、线束和无电释放。
4. 依据 CMF 板创建真实材料分区与可换件边界，再做 RF/IR/声学、阻燃、耐候、清洁和色差试片。
5. 每轮曲面冻结后，按 `03_cmf_and_release_gates.md` 回归相应 G0–G6 证据，不以“看起来可行”关闭问题。
