# WorkCore E6 四态安全状态机与初步 FMEA

E6 的用户叙事只有 Follow、Ride、Café、Focus 四态；越障、移乘、维修和户外包仍是受控工程/附件状态。原 v37 的基座层感知在折叠 Follow 态持续工作，但这不等于产品已经具备公共空间通用自动驾驶能力。

## 状态定义

| 状态 | 允许动作 | 必须满足 |
|---|---|---|
| FOLLOW_CLOSED | 空载折叠后在白名单私域路线受限随行 | 座椅明确无人；靠背/脚踏/桌板/摇杆收纳；UWB主人身份与视觉可信；基座感知、悬崖检测、触觉膜、轮速/IMU和独立安全控制器健康；速度≤0.8m/s；任一关键可信度丢失即制动 |
| RIDE_READY | 载人社区慢行 | 座椅占用；脚踏展开并正锁；桌板收纳；两侧扶手正锁；摇杆授权；默认速度≤1.0m/s；断电制动可用 |
| CAFE_PARKED | 驻车社交、无桌或横向单桌 | 驻车制动硬件施加；驱动接触器断开；桅杆低位；标准版右摇杆已入仓；右桌板完成前移、空桌旋转90°和80mm回移正锁；左侧保持开放（镜像版反向） |
| FOCUS_WORK | 双桌面展开、智能脊柱升起并恢复工作上下文 | 驻车制动施加；驱动接触器断开；双桌面正锁；智能脊柱锁位；相机物理隐私状态明确；上下文恢复不得影响安全域 |
| TRAVEL_STOWED | 工程收纳检查与充电 | 靠背/桅杆/桌板/脚踏收纳；两个设备仓正锁；随行未授权时保持驻车 |
| OBSTACLE_ASSIST | 无人状态拔出后置拉杆、后倾约8°并由轮毂低扭矩助攀 | 座椅无人；脚踏/桌板/抽屉收纳锁止；靠背与桅杆折叠；顶棚收回；拉杆双锁；四轮制动可随时施加 |
| OCCUPIED_READY | RIDE_READY 的工程别名 | 与 RIDE_READY 相同 |
| ZERO_TURN | 低速原地掉头 | 桌板/顶棚收纳；两侧扶手锁闭；脚踏无外部障碍；轮速 ≤0.30 m/s；扭矩 2 s 渐增 |
| TRANSFER_OPEN | 右侧移乘 | 驻车制动硬件施加；驱动接触器断开；桌板收纳；右上扶手机械解锁并后外摆到位 |
| SERVICE_DRAWER | 单个通用设备仓开启 | 驻车；对应锁扣已解锁；另一仓保持锁止；仓内只允许受控充电，不承诺双高功率电脑闭仓运行 |
| LOW_ENERGY_RECOVERY | 主电池达到按温度、老化、坡度和返航距离动态计算的保留边界 | 不再开始新的Follow或构型动作；以声光和本地界面给出可解释剩余能力；只允许安全链健康时的持续按压低速脱困/对接，松手即制动；不得靠关闭安全传感器换取续航 |
| STRANDED_SAFE | 主牵引能量、关键传感或驱动不可用且无法自行到达安全停放点 | 机械制动施加；60Wh独立安全电源维持控制器、状态灯和求助；提供从通道移走所需的受控机械制动释放/牵引点和单人救援流程，禁止把收纳态估算已约113kg且量产质量未冻结的整机抬起作为用户任务 |
| DESK_ACCESS | 临时开扶手盖板 | 驻车；驱动接触器断开；桌板保持折叠；盖板开启动作限力 |
| DESK_TRANSLATE | 折叠桌板在内部护槽内前移 | 驻车；人体侧向净距成立；前移终点双确认 |
| DESK_LID_RELATCH | 关闭并锁住扶手盖板 | 桌板已前移离开盖板；盖板双锁位一致 |
| DESK_UNFOLD | 桌板只在人体前方展开 | 驻车；前移终点锁到位；扶手盖板已闭合；人体核心包络净距成立 |
| DESK_CAFE_ROTATE | Café单板绕质心旋转90° | 桌面为空；板面处于前向清空位；0°锁已解除；人体扫掠区清空；旋转到90°硬止挡并由双剪锁销确认 |
| DESK_CAFE_RETURN | 横向桌板回移80mm进入使用位 | 90°旋转锁已确认；前后滑轨无异物；回移终点正锁；右摇杆保持入仓；左屏/Qi无遮挡 |
| DESK_DEPLOYED | 展开桌板并使用 | 驻车；两枚正锁销到位；桌面状态禁止驱动 |
| OUTDOOR_PACKAGE_DEPLOYED | 可拆户外包展开 | 驻车；智能脊柱双锁；附件身份与锁位确认；风速低于阈值；不属于基础整机 |
| EMERGENCY_RETRACT | 顶棚最快安全回收 | 风超限、传感器不一致、失电储能触发、控制器故障或用户急停 |
| FAULT_SAFE | 禁止危险运动并提示人工处置 | 状态未知、锁位未知、夹伤/卡滞或重复回收失败 |

控制器重启后不得假设机构位置；必须读取独立的收纳位、锁销位、脚踏锁位、仓门锁位和电流/张力诊断信号。Jetson/AI 计算只可提交速度或轨迹请求，不能直接授予扭矩、STO复位或制动释放。运动许可由独立安全控制器、硬件急停和机械制动链决定。任何互锁被旁路都应记录维护事件。桌板和脚踏必须提供无电机械释放，紧急离开不得依赖软件、无线连接或电磁闩。

## 初步 FMEA

| 失效 | 主要后果 | E6 检测 | E6 安全动作 | 仍需验证 |
|---|---|---|---|---|
| 随行绑定到错误目标/身份中继 | 跟错人、碰撞或资产丢失 | 配对UWB密钥、距离/方向连续性、视觉一致性与本地授权同时成立 | 撤销扭矩、机械制动、低亮度/声音提示主人接管 | 多人交叉、遮挡、尾随、重放/中继攻击 |
| 随行目标或视觉置信度丢失 | 继续盲走撞人/物 | UWB、3D视觉、轮速和IMU独立超时；目标丢失目标≤0.5s | 不猜测目标方向，立即按实测保护距离停车 | 0.8m/s全载荷/坡面/湿地制动距离与总链路延迟 |
| 日照、雨雾、污损使低位光学感知失效 | 漏检障碍或误停车 | 光学质量、遮挡/污损诊断和多模态合理性 | 降速至0并提示清洁/人工操控；禁止仅靠UWB继续 | 户外日照、雨雾、泥点、逆光；社区应用整机风险评估 |
| 悬崖/触边检测失效 | 跌落台阶或碰撞旁人 | 四路向下检测交叉检查、触觉膜双通道、周期自检 | 任一不可信即禁止Follow | 黑色/镜面地面、斜坡边缘、传感器机械撞击后漂移 |
| 有人/重物在座椅上却进入Follow | 人员跌落或车辆不稳定 | 双区占用垫、重量趋势、靠背/脚踏/摇杆状态 | Follow许可硬件拒绝；保持驻车 | 儿童、宠物、软包和局部放置物误判 |
| AI计算输出越过安全域 | 非预期运动 | 独立安全MCU、白名单意图接口、双通道STO/制动许可 | AI链路失效不影响机械停车；异常请求丢弃并记录 | 总线注入、Jetson重启、时序竞争、看门狗与安全分析 |
| 单个风传感器失效/漂移 | 未及时回收或误回收 | 双通道差值、合理性和超时 | 进入回收；禁止再次展开 | 阈值、滞回、污染/结冰 |
| 全车失电 | 顶棚停留在危险位置 | 欠压硬件信号 | 弹簧/储能回收，机械制动限速 | 负载下回收时间与温升 |
| 卷筒或臂卡滞 | 夹伤、撕布、机构过载 | 电流、速度、张力不一致 | 停止，短距离反向，仍失败则故障锁定 | 力限值和夹伤试块 |
| 桅杆绕绳断裂 | 顶棚下落 | 双路径张力/位置不一致 | 机械防坠和双锁销承载 | 防坠距离、冲击载荷 |
| 桅杆锁销未到位 | 风载下滑移 | 双独立到位开关 | 禁止顶棚展开 | 污染、公差、误报 |
| 抽屉仅靠滑轨保持 | 行驶中弹出 | 锁扣位置开关 | 禁止行驶或显著限速 | 冲击台和斜坡测试 |
| 桌板仅靠摩擦铰链 | 突然折叠 | 两枚锁销检测 | 禁止承载提示；驱动禁用 | 单边满载和疲劳 |
| 桌板未前移就展开 | 扫过乘员躯干/手臂 | 前移终点双确认 + 机械顺序槽 | 机构物理阻止展开 | 假人扫掠、误用和磨损 |
| Café桌面带物旋转或未到清空位即旋转 | 电脑/杯具甩落、撞击乘员 | 桌面使用提示、清空位双确认、机械顺序槽 | 物理阻止转盘解锁；保持驱动断开 | 5F～95M误用、污染和20,000次顺序循环 |
| Café转盘或80mm滑轨未正锁即承载 | 桌面偏转、坠落或夹伤 | 0/90°位置双确认、滑轨端位确认与消隙楔 | 禁止进入DESK_DEPLOYED并提示机械复位 | 380Nm证明载荷、外缘偏载、倚靠和锁销单故障 |
| 盖板未关就展开桌板 | 盖板翘起、夹手或干涉前臂 | 盖板双通道锁位 + 机械顺序槽 | 物理阻止展开；保持驱动断开 | 污染、公差极限和 20,000 次循环 |
| 移乘扶手未锁就驱动 | 乘员侧向跌落、机构甩动 | 双锁位开关 + 独立安全触点 | 接触器断开、四轮制动 | 锁舌磨损、误锁和无电释放 |
| 原地转向持续时间过长 | 胎温、电机温升、侧向冲击 | 轮速/电流/温度积分 | 降扭并退出 ZERO_TURN | 高摩擦地坪、低胎压、满载 |
| 桌板或脚踏卡滞 | 乘员无法离开 | 位置超时、锁位不一致 | 驱动禁用；允许无电机械快拆 | 10 秒紧急离开测试 |
| 脚踏未锁 | 足部跌落、卷入轮组 | 双锁位检测 | 禁止载人驱动 | 动载、冲击和污染 |
| 座椅占用误判或状态不确定 | 有人时错误进入Follow，或载人许可使用错误边界 | 双区占用垫、重量趋势、线路诊断与构型合理性 | 任何未知、不一致、断线或卡死均按“可能有人”处理并禁止Follow；载人许可也保持驻车直至独立通道一致 | 儿童、宠物、软包、局部载荷、断线、漂移、卡死与重启 |
| 无线充电异物/温升 | 烫伤或起火 | FOD、温度、电流异常 | 立即停止充电并报警 | 全材料组合温升试验 |
| 手机在位时左盖板开启 | 手机跌落、夹线或线圈损坏 | 在位传感器+盖板锁位 | 拒绝解锁盖板并提示先移走手机 | 污染、厚手机壳、传感器断线和误报 |
| 越障拉杆未锁或载人时误伸出 | 拉杆回缩、夹伤、跌落或失稳 | 占用传感、机构收纳位、左右双锁和制动状态 | 禁止拉杆解锁/轮毂助力；进入FAULT_SAFE | 锁销磨损、断线、单边锁、坡面和20,000次疲劳 |
| 控制器重启/状态丢失 | 危险动作顺序 | 启动自检与绝对位置输入 | 保持停止，执行受限回零/人工确认 | 掉电时序和通信故障注入 |
| 单轮越障导致刚性底盘翘轮 | 失去附着、冲击乘员 | 摇臂角度、轮速差、IMU | 降速/停止；禁止斜向继续攀爬 | 50/60 mm、对角障碍、摇臂疲劳 |
| 电池盒温升或压力异常 | 烟气/火焰进入乘员区 | 双温度、压力/气体趋势、绝缘/电流 | 主接触器断开；后向泄压；报警撤离 | 单电芯传播、浸水、碰撞和排气路径 |
| 低SOC、低温/老化降额或充电点不可用 | 收纳态估算已约113kg的整机停在门口、坡道或公共通道，用户无法处理 | 库仑计量、单体电压、温度、SOH、路线能量和备用电源自检 | 提前进入LOW_ENERGY_RECOVERY，禁止新的自主旅程；仍失去牵引则进入STRANDED_SAFE并保留可见求助与受控制动释放 | 动态保留量模型、坡面/低温/老化、错误SOC、无可用Dock和单人救援演练 |
| 独立安全备用电源失效或容量衰减 | 主电失效后急停、状态、求助或机构安全回收不可用 | 启动/周期带载自检、容量与内阻趋势、寿命计时 | 主牵引上电前拒绝放行或限制为维修态；不得把备用电源故障静默降级 | 60Wh实际任务谱、低温、老化、单故障和更换后EOL测试 |

## 可执行参考策略

`cad/motion_authority.py` 是用于状态真值表测试的无副作用参考判定核。它只会在输入全部明确时给 `RIDE` 或受限空载 `FOLLOW` 授予牵引；`CAFE_LOCKED`、`FOCUS`、低能量恢复、受困和故障态始终为零牵引，任一共用安全输入未知都施加制动。它是需求证据，不是量产固件，也不能替代独立安全控制器、诊断覆盖率分析和硬件验证。

## 放行说明

E6 只给出功能安全架构，不声明整机 PL、SIL 或任何法规等级。即使候选扫描器、STO或MCU具备器件级安全能力，也不等于社区随行应用自动获得相同等级。风险等级、所需诊断覆盖率、硬件冗余和软件开发流程必须在目标市场、产品分类和最终用途确定后由合格安全工程师确认。
