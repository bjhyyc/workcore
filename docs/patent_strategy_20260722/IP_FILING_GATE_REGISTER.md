## 5. 每次改动的 IP 评审问题

1. 是否改变 D1—D9 中候选受保护局部的位置、比例、轮廓、色彩图案或状态？
2. 是否增加原首申没有披露的结构、算法输入输出、异常路径或技术效果？
3. 是否接近 Piaggio、Toyota、Pride、Ford、Suzhou KD 等待核家族的权利要求？
4. 是否可以通过功能等同的第二实施例扩大说明书支持，而不牺牲极简外观？
5. 是否必须在演示、采购询价、供应商评审或测试前补申请？
6. 该内容从成品可否容易反向获得？若不能，专利公开是否优于商业秘密？

任何一项答案为“是/不确定”，先进入专利评审，不直接公开。
