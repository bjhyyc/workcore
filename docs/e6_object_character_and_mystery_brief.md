# WorkCore E6 新物品特征与神秘感工业设计简报

Status: E6R2 product/industrial-design input for formative prototypes. It defines what the object should communicate and how that intent is falsified; it is not Class-A release, styling approval or safety evidence.

## 1. 新物品命题

WorkCore 不是“轮椅 + 折叠桌 + 跟随箱 + AI 屏”的可见相加。它应被感知为一种会随人的任务在空间中收敛和展开的个人场域载体：闭合时保留能力但不炫耀，载人时给人主体性，停稳后才打开社交或专注边界，数字上下文只在正确的人和正确的物理状态下回来。

神秘的是尚未显露的能力，不是它的意图。旁观者必须随时能判断：它会不会动、哪边安全、是否已停稳、工作相机是否遮挡、是否需要接管。任何依靠猜测运动方向、隐藏故障或伪装感知来制造的“未来感”都不合格。

## 2. 一套物品语法，而不是四台拼装产品

### 2.1 恒定基因

- **低而完整的核心体量**：底座读作一个受控、稳定、有重量的整体，不读作设备机柜或四轮底盘；轮端可以被体量吸收，但轮胎接地、转向意图和安全边界不能被视觉欺骗。
- **一条感知地平线**：Follow 所需的低位感知窗、触边和状态表达收进同一连续带，避免四处粘贴“机器人眼睛”。工作相机属于上部脊柱，并以物理遮挡与导航感知明确区分。
- **一个变形逻辑**：所有缝、盖、桌、脚踏、扶手和脊柱沿少数可追溯的几何线索运动；用户不应看到为了每个状态临时冒出的第二套零件。
- **一个脚踏总成**：A08 的平台、左右支撑、左右护套与手动正锁在所有状态保留相同物理 occurrence、材料、质量和定义，只允许姿态变化。Follow 默认收纳；Ride 默认展开并正锁；Café/Focus 默认收纳以让双脚自然落地，但在驻车、扫掠区清空并明确请求时可展开同一脚踏。可选展开是机构子状态，不是第五种产品人格，也不得进入四态主渲染冒充默认状态。
- **可读的前后与接近侧**：整体可简洁，但不得成为无方向的黑箱。坐入方向、Follow 前进方向、Café 开放侧、急停/服务侧都要在轮廓和触点上成立。
- **材料真实**：承力处显得可靠、接触处显得温和、传感处显得精确、维修处显得可拆。不得靠大面积钢琴黑、伪木纹或连续发光带掩盖粗糙分件。

### 2.2 必须消失的旧品类噪声

- 医疗器械式管架、裸露线束和附加靠垫；
- 办公椅的五星脚、气弹簧和随意旋转感；
- 工具车的抽屉墙、护栏、脚轮和把手森林；
- 行李箱的手提暗示、拉杆支配造型和虚假轻量感；
- 服务机器人的拟人眼睛、RGB 情绪灯、无必要语音和“正在看你”的镜头姿态；
- 概念车式不可维护封壳、无功能黑缝和只在渲染里成立的悬浮面。

## 3. 四态的关系变化

| 状态 | 第一读感 | 只在此时显露的能力 | 必须保持可读 | 设计失败信号 |
|---|---|---|---|---|
| Follow | 安静、闭合、与主人保持距离的伴随物 | 低位感知地平线与克制的行进确认 | 空载、前进方向、保护距离、即将停车/已停 | 像可手提行李；像宠物追逐；旁观者不知道它会向哪走 |
| Ride | 人进入后形成一个受保护但不封闭的个人载体 | 脚踏、扶手与控制权围绕人建立 | 乘员是主体；手动控制/急停；桌面仍完全收纳 | 像医疗座椅；控制器像后加；外壳高于人并夺走主体性 |
| Café | 驻车后只打开一侧，主动给另一侧的人留空间 | 单侧桌面横向形成共享边界，固定前置控制岛保持外露但明确失去牵引授权 | 驻车、开放接近侧、双脚默认可落地、右手控制可达、杯/设备边界、禁止移动 | 像坏掉的半张桌；控制岛被桌板遮挡或移到手后方；桌面展开却保留牵引授权 |
| Focus | 两侧闭合成个人工作场，智能脊柱在停稳后升起 | 本地任务恢复、受控显示/声学/光与工作相机 | 驻车、双脚默认可落地、身份、隐私片、可离开路径、部分恢复原因 | 只是“大桌版 Ride”；屏幕比人先醒；相机静默打开；线缆破坏完整性 |

Outdoor Pack 不得成为第五种核心人格。它是可拆、可识别、可单独维护和定价的天气附件；安装后仍服从四态语言，并在风超限或故障时可解释地收回。

## 4. 魔法时刻的因果链

真正独特的体验不是一次自动展开，而是一条用户能理解、系统可验证的因果链：

1. 产品随人到达，但在门槛、拥挤或路线不确定前停住；
2. 用户进入或把它停到指定位置，机械状态先明确；
3. Café 只打开社交所需一侧，Focus 才形成完整工作边界；
4. 正确用户完成本地鉴权后，正确任务在 P95 10 秒目标内成为可用状态；
5. 缺少设备、网络、权限或隐私同意时，只恢复安全的本地部分并解释缺什么；
6. 离开、重新移动或身份失配时，个人内容退回中性状态，采集保持更私密的一侧。

如果这条链必须由讲解员、隐藏遥控器、预先摆好的空桌、稳定云网络或现场工程师才能成立，它就还不是产品能力。

## 5. 典型场景中的新物品行为

| 场景 | 产品应做什么 | 神秘感来源 | 不能发生 |
|---|---|---|---|
| 家中准备出发 | 设备和日常物进入明确容器，产品闭合并确认主人；高频物仍可取 | 大体量迅速收敛为安静整体，能力被藏住 | 要用户清空所有物品、整理外露线或搬起整机 |
| 门厅/电梯前 | 在白名单边界前停住，指明需要接管；保持不堵通道 | 它知道能力边界且主动克制 | 猜门的动作、尾随陌生人、自主乘梯承诺 |
| 受控园区移动 | 人坐入后工作设备不必重新装袋，控制权明确交给乘员 | 同一物品从伴随者变成人的载体 | Follow 与 Ride 身份混淆；未知占用仍授权 |
| Café 会面 | 停稳并撤销牵引授权，右侧控制始终留在扶手前端；只在清空后旋转单桌，为对面人留出开放面 | 物品从“围绕我”变成“连接我们”，能力由状态而非藏起控制器来克制 | 带杯旋转、桌边扫人、桌板遮挡控制、展开后仍能移动 |
| 临时专注 | 双桌与脊柱按顺序出现，正确本地任务恢复；隐私硬件先于内容可见 | 物理空间和数字任务一起回来 | 相机/麦克风沿用旧会话；错误用户看到任务名称 |
| 低电/断网 | 提前收窄能力，保留本地核心并说清原因；必要时进入可救援安全态 | 有能力的物品懂得优雅退场 | 关闭安全感知换续航；113kg级整机堵在通道且无牵引/救援点 |
| 清洁/维修 | 服务边界、断电、热表面和机械释放有明确物理语法 | 平时完整，授权后结构逻辑显露 | 维修靠撬壳；清洁人员触发机构；服务状态假装正常 |
| 转售/换用户 | 旧用户上下文可验证清除，新用户像接手一件干净的新物品 | 物品有连续性，但不偷偷携带前任 | 残留身份、密钥、任务缩略图或路线数据 |

儿童、宠物、软包、雨水、污渍、戴手套、听力/色觉差异、旁观者不懂产品、用户赶时间等不是边缘情况，必须进入形成性测试。

## 6. 动作、光与声音纪律

- 每个动作先表达意图，再运动，再确认结束；预提示的时长、可见距离和声级由可用性与场地背景测试冻结，不凭审美指定。
- 机械动作只呈现必要速度变化，避免为了“有生命”而摆动、呼吸或主动靠近。
- 状态光数量要少，颜色不是唯一通道；移动、停稳、隐私关闭、导航感知、故障/接管的语义互不复用。
- 默认不用人格化语音。声标只承担方向、危险、完成或需接管，并验证在安静咖啡馆和嘈杂门厅中都不过度惊扰。
- Follow 停车、Café 锁止、Focus 隐私和低能量退化必须在 2m 外可读；装饰灯效不得覆盖这些信号。
- 机构、风扇、制动、胎面和提示音分别做声品质测试；低分贝但尖锐、周期性或来源不明同样失败。

## 7. Class-A 与体验原型交付物

下一轮外观不能只产一张漂亮渲染。至少需要：

1. 四态同一物理件 ID 的全尺寸数字样机和姿态不变质量对账；
2. 1:1 前/后/左右轮廓与 2m、5m 状态可读性板；
3. 可制造分件、拔模、密封、紧固、维修拆装、线束动态区和传感透过区；
4. Café 全尺寸动作/误用台架及 Focus 设备、杯具、线缆、手臂和逃生路径实物；
5. 三种表面方案的清洁、皮脂、刮擦、UV、消毒剂和老化限度样；
6. 动作—灯—声—屏的时序原型，包含正常、部分恢复、拒绝、低能量和故障；
7. 未解释 5 秒观看、90 秒旅程和真实中断—恢复的原始视频、行为编码与访谈逐字记录。

## 8. 设计放行门

只有同时满足以下条件，才能说“新物品特征”在产品中成立：

- 目标用户在无品类提示时能识别四态的用途差异，且不误判可手提、自由上路或无人照护；
- 未受训旁观者在 5 秒内达到 launch validation 中的运动、安全接近、隐私/故障可读性门槛；
- 用户演示后自发描述的是“任务和我的空间一起移动并恢复”，而不只是电动椅、折叠桌或跟随箱；
- 所有被认为“神奇”的行为都能在断网、缺设备、错误身份和故障下安全退化并解释；
- Class-A 外观没有牺牲传感、制动、热、结构、维修、清洁、制造公差和成本路径；
- 正式先前技术检索、FTO 与外观/发明专利策略完成，未把拥挤赛道中的通用品类特征误当独占创新。

若安全意图与神秘感冲突，安全意图优先；若独特价值只能靠增加又一机构或屏幕来解释，回到旅程和 Context Continuity，而不是继续堆功能。
