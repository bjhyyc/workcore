# WorkCore E6 接口控制草案

本文件定义样机阶段的主基准和供应件包络。所有孔位应由结构基准标注，禁止从外观壳体或软包边缘反推。

## 整机基准

- 基准 A：底盘上平面，理论 Z=140 mm；焊后精加工或使用可更换加工基板建立。
- 基准 B：整机纵向中心面，Y=0。
- 基准 C：后横梁中心面，X=210 mm。
- 车轮接地点定义 Z=0；外壳仅为外观/防护件，不参与定位闭环。

## 尺寸链原则

- 焊接底盘定位面：焊后统一精加工或加装加工基板，平面度目标 0.5 mm/500 mm。
- 钣金抽屉和外壳：外形公差不进入滑轨预紧尺寸链；使用独立内骨架和长圆孔。
- 塑料外壳：周边名义缝隙不小于 1.5 mm；活动件动态间隙不小于 3 mm。
- 桅杆导向：用三档厚度的 POM 垫片选配，首件以推力和摆差共同验收。
- 线束/软管：所有活动接口必须定义最小弯曲半径、固定点、服务环和全行程扫掠体。
- 供应商变更：任何包络、孔位、连接器、额定载荷或固件变化都触发接口复核，而不是现场修孔。

## 必须由样机测量回写的项目

焊后 A/B/C 基准、车轮接地点、滑轨实际侧隙、抽屉面板齐平度、桅杆启动力/摆差、顶棚收纳堆叠、桌板中缝、座椅与扶手软包压缩量、线束全行程净空。
