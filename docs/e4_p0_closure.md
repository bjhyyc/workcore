# WorkCore E4 P0 闭环矩阵

## 状态定义

- **设计闭环**：危险已落实到参数、实体几何、硬件架构和自动检查，允许制造工程样机。
- **物理放行**：完成规定样机、人在环、环境和故障注入试验后，才允许载人或量产。

E4 每次构建必须让几何、工程、通行性和电气热管理自动检查全部通过；具体数量以最新 `build/production_readiness_report.json` 为准。检查数量会随规则增加而变化，不能把“既有规则 0 失败”误写成“模型 0 风险”。生产准备门、法规证据和物理试验与自动检查分开统计；任何一项物理放行试验缺失，都不得对外宣称量产或载人认证完成。

## 禁止对外宣称

在物理放行完成前，禁止使用“可量产载人”“60 mm 全路况越障”“任何电梯均可进入”“适配所有 SUV 后备箱”“老人无需照护即可使用”等表述。

允许的工程表述是：E4 已完成参数化设计闭环，可制造 P0 工程样机；50 mm 是待样机确认的额定目标，60 mm 是严格条件下的计算/试验上限。

## 样机顺序

1. 无人配重底盘：制动、失电、转向、轮载和越障。
2. 150 kg 假人：单轮/对角障碍、急刹、侧坡和机构误动作。
3. 5F～95M 人在环静态样机：桌板、移乘、逃生、视野和操作力。
4. 受控低速载人：先照护模式，再创作模式；逐步开放速度和障碍高度。
5. 环境与耐久：水、尘、温度、盐雾、线束弯折、20,000 次机构循环和整车振动。
